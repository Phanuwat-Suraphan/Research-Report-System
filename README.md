# เว็บเผยแพร่ผลงานวิจัยและนวัตกรรมครู — โรงเรียนเจ้าพ่อหลวงอุปถัมภ์ ๑

เว็บไซต์รวบรวมและเผยแพร่ **ผลงานวิจัยในชั้นเรียนและนวัตกรรม** ของคณะครูและผู้อำนวยการ
**ทุกคนเข้าชมได้โดยไม่ต้องเข้าสู่ระบบ** ใส่รหัสเฉพาะตอนจะ **เพิ่ม / แก้ไข / ลบ / รับรอง** เท่านั้น

> รหัสเริ่มต้นสำหรับแก้ไข: **`123456`** (เปลี่ยนได้ที่หน้า "จัดการระบบ")

## ความสามารถ

**สำหรับผู้เข้าชมทั่วไป (ไม่ต้องใช้รหัส)**
- ดูผลงานทั้งหมดเป็นแกลเลอรี พร้อมภาพอินโฟกราฟิกเป็นหน้าปก
- ค้นหา/กรองตามประเภท (วิจัย/นวัตกรรม) กลุ่มสาระ ปีการศึกษา และสถานะการรับรอง
- กดเปิดไฟล์ผลงานบน Google Drive ได้ทันที หรือดูตัวอย่างในหน้าเว็บโดยไม่ต้องออกไปไหน
- **ดูคลิป YouTube เล่นเกม และเปิดเว็บไซต์/เอกสารที่ครูทำขึ้นได้ในหน้าเดียว**
- เปิดและสั่งพิมพ์ **หน้ารับรองขนาด A4** ของผลงานที่ผู้อำนวยการรับรองแล้ว

**สำหรับคณะครู (ใส่รหัส 123456)**
- ส่งผลงานโดย **วางลิงก์ Google Drive** — ไม่มีการอัปโหลดไฟล์ ไฟล์ต้นฉบับยังอยู่ในไดรฟ์ของครูเสมอ
- เลือกประเภทผลงาน: **งานวิจัยในชั้นเรียน** หรือ **นวัตกรรมการเรียนการสอน**
- ใส่ **อินโฟกราฟิก** จากไดรฟ์ได้ (ไม่บังคับ) ระบบจะนำมาแสดงเป็นภาพหน้าปกและภาพเต็มในหน้าผลงาน
- ใส่ **สื่อออนไลน์** ได้อีกหลายรายการ: คลิป YouTube, เกม, เว็บไซต์, เอกสารออนไลน์ — ผู้ชมกดดู/เล่นได้ทันที
- แก้ไขและลบผลงานได้ (ลบแล้วกู้คืนได้)

**สำหรับผู้อำนวยการ**
- **อัปโหลดรูปลายเซ็น** (PNG/JPG/WebP) เก็บไว้ครั้งเดียว แล้วใช้รับรองผลงานได้ทุกชิ้นด้วยคลิกเดียว
- ลงนามรับรองผลงาน ระบบออก **เลขที่เอกสารรับรอง** และวันที่แบบไทย (พ.ศ.) ให้อัตโนมัติ
- ครูสั่งพิมพ์ **หน้ารับรอง A4** ที่มีลายเซ็นจริงไปแนบรายงานได้ทันที

## ข้อมูลไม่หายถาวร

ข้อกำหนดสำคัญของโรงเรียนคือข้อมูลต้องไม่สูญหาย ระบบจึงป้องกันไว้ 5 ชั้น:

| กลไก | ป้องกันอะไร |
|---|---|
| **ลบแบบย้ายลงถังขยะ** | ไม่มีการลบจริงออกจากฐานข้อมูล กู้คืนได้จากหน้าจัดการระบบตลอดเวลา |
| **ประวัติทุกเวอร์ชัน** | ทุกครั้งที่แก้ไข/ลบ/รับรอง ระบบเก็บสำเนาเวอร์ชันก่อนหน้าไว้ครบ (รวมลิงก์ทั้งหมด) ย้อนกลับได้ทุกเวอร์ชัน และการย้อนกลับเองก็ย้อนได้อีก |
| **สำรองอัตโนมัติรายวัน** | สำเนาฐานข้อมูลถูกสร้างวันละครั้งและเก็บย้อนหลัง 14 ชุด |
| **ดาวน์โหลดไฟล์สำรอง** | กดปุ่มเดียวได้ไฟล์ฐานข้อมูลทั้งก้อนไปเก็บไว้นอกเซิร์ฟเวอร์ (แนะนำภาคเรียนละครั้ง) |
| **Persistent disk** | `render.yaml` ตั้ง disk ถาวรไว้แล้ว ข้อมูลไม่ถูกล้างเวลา deploy ใหม่ |

ไฟล์ผลงานจริงยังอยู่ใน **Google Drive ของครูเอง** ระบบเก็บแค่ลิงก์ จึงไม่มีทางที่ไฟล์ต้นฉบับจะหายไปกับเซิร์ฟเวอร์
รูปลายเซ็นผู้อำนวยการเก็บอยู่ใน **ฐานข้อมูล** (ไม่ใช่ไฟล์ลอย ๆ บนดิสก์) จึงถูกสำรองไปพร้อมกันเสมอ

> ⚠️ **ข้อควรระวัง:** แผน Free ของ Render **ไม่รองรับ persistent disk** ถ้าใช้แผน free ข้อมูลจะหายทุกครั้งที่ deploy ใหม่
> เว็บจะขึ้นคำเตือนใน log ให้เมื่อไม่ได้ตั้ง `DATA_DIR` — สำหรับใช้งานจริงต้องใช้แผน **Starter ขึ้นไป** ตามที่ตั้งไว้ใน `render.yaml`

## วิธีรันบนเครื่อง

ไม่มี dependency ให้ติดตั้ง (ใช้ Node.js ล้วน ๆ ต้องเป็นเวอร์ชัน 22.5 ขึ้นไป)

```bash
node server.js          # เปิดที่ http://localhost:3000
node scripts/smoke-test.js   # รันทดสอบทั้งระบบ 55 ข้อ
```

## นำขึ้นใช้งานจริง (ให้คนทั่วไปเข้าชมได้)

โค้ดนี้เป็นเว็บเซิร์ฟเวอร์ + ฐานข้อมูล **จึงใช้ GitHub Pages ไม่ได้** (GitHub Pages เปิดได้เฉพาะไฟล์นิ่ง ๆ ไม่มีระบบบันทึกข้อมูล)
ให้ deploy บน Render ซึ่งฟรี/ถูกและอ่านค่าจาก `render.yaml` ให้อัตโนมัติ:

1. เข้า [render.com](https://render.com) → **New** → **Blueprint**
2. เลือก repository นี้ แล้วเลือก branch
3. กด **Apply** — Render จะอ่าน `render.yaml` ตั้งค่าให้ทั้งหมด รวมถึง persistent disk
4. รอ deploy เสร็จ จะได้ URL สาธารณะ เช่น `https://research-report-system.onrender.com` แจกให้ใครก็เปิดดูได้ทันที

**สิ่งที่ควรทำทันทีหลัง deploy**
1. เข้าหน้า **จัดการระบบ** → ใส่รหัส `123456`
2. **เปลี่ยนรหัส** เป็นรหัสที่เฉพาะคณะครูทราบ (เว็บเปิดสาธารณะ ใครก็เดารหัสเริ่มต้นได้)
3. อัปโหลด **รูปลายเซ็นผู้อำนวยการ** พร้อมกรอกชื่อ-ตำแหน่ง
4. ปรับรายชื่อ **กลุ่มสาระการเรียนรู้** ให้ตรงกับของโรงเรียน

## การตั้งค่าผ่าน Environment Variables

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `EDIT_PASSCODE` | `123456` | รหัสสำหรับเพิ่ม/แก้ไข/ลบ/รับรอง (รหัสที่เปลี่ยนในหน้าเว็บจะถูกใช้แทนค่านี้) |
| `DATA_DIR` | `./data` | ที่เก็บฐานข้อมูลและไฟล์สำรอง — ต้องชี้ไป persistent disk เมื่อใช้งานจริง |
| `SCHOOL_NAME` | โรงเรียนเจ้าพ่อหลวงอุปถัมภ์ ๑ | ชื่อโรงเรียนที่แสดงทั้งเว็บและบนหน้ารับรอง |
| `UNLOCK_HOURS` | `8` | ปลดล็อกครั้งหนึ่งใช้ได้กี่ชั่วโมงก่อนต้องใส่รหัสใหม่ |
| `BACKUP_KEEP` | `14` | เก็บไฟล์สำรองย้อนหลังกี่ชุด |
| `PORT` | `3000` | พอร์ตที่เปิดให้บริการ |

ลิงก์จากที่อื่นหรือลิงก์หน้าไดรฟ์ส่วนตัวจะถูกปฏิเสธพร้อมบอกวิธีแก้เป็นภาษาไทย

**ช่องสื่อ** รับลิงก์อะไรก็ได้ โดยผู้ให้บริการเหล่านี้จะถูก **ฝังให้ดู/เล่นในหน้าเว็บได้เลย**:
YouTube · Scratch · Wordwall · Canva · Google Drive/Docs
ผู้ให้บริการอื่นระบบจะแสดงเป็นปุ่มเปิดแท็บใหม่แทน (เพื่อความปลอดภัย ไม่ฝังหน้าเว็บที่ไม่รู้จักลงในเว็บโรงเรียน)

> อย่าลืมตั้งค่าแชร์ไฟล์ใน Drive เป็น **"ผู้ที่มีลิงก์"** ไม่เช่นนั้นคนอื่นจะเปิดดูไม่ได้

## โครงสร้างโค้ด

```
server.js                 เปิดเซิร์ฟเวอร์ + ตั้งเวลาสำรองข้อมูล
src/app.js                router ทุกเส้นทาง + การตรวจรหัส/CSRF
src/db/index.js           โครงสร้างฐานข้อมูล SQLite
src/lib/gate.js           ระบบรหัสผ่าน (cookie เซ็นชื่อ ไม่มีตาราง session)
src/lib/driveLink.js      ตรวจและแปลงลิงก์ Google Drive
src/lib/mediaLink.js      ตรวจลิงก์สื่อ + สร้าง URL สำหรับฝังหน้าเว็บ
src/lib/certificate.js    หน้ารับรอง A4
src/lib/revisions.js      ประวัติทุกเวอร์ชัน + การย้อนกลับ
src/lib/backup.js         สำรองฐานข้อมูลอัตโนมัติ
src/pages/                หน้าเว็บทั้งหมด (แกลเลอรี, ผลงาน, ฟอร์ม, จัดการระบบ)
scripts/smoke-test.js     ทดสอบทั้งระบบ 55 ข้อ
```

`docs/system-design.md` เป็นเอกสารออกแบบของระบบรุ่นแรก (แบบมี login และ workflow ลงนาม 4 ขั้น) เก็บไว้เป็นข้อมูลอ้างอิงเท่านั้น ระบบปัจจุบันเป็นเว็บสาธารณะตามที่อธิบายด้านบน

## ข้อจำกัดที่ควรทราบ

- ใช้ **รหัสร่วมกันรหัสเดียว** ไม่มีบัญชีรายบุคคล จึงระบุตัวผู้แก้ไขเป็นรายคนไม่ได้ — ระบบจึงบันทึก IP และเวลาของทุกการเปลี่ยนแปลงไว้ในหน้าจัดการระบบแทน และเก็บประวัติทุกเวอร์ชันไว้ให้ย้อนได้
- หน้ารับรองเป็นการลงนามด้วย **รูปลายเซ็น** ไม่ใช่ลายเซ็นดิจิทัลแบบมีใบรับรอง (PKI) เหมาะกับการใช้งานภายในโรงเรียน
- การฝังไฟล์ Drive ในหน้าเว็บจะแสดงผลก็ต่อเมื่อเจ้าของตั้งค่าแชร์เป็น "ผู้ที่มีลิงก์" แล้ว
