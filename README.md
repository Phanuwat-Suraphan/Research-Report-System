# Research Report System

ระบบรายงานผลการวิจัยในชั้นเรียนและนวัตกรรมครูแบบดิจิทัล — รองรับ workflow การส่ง-ตรวจ-ลงนามหลายขั้นตอน (ครู → หัวหน้ากลุ่มสาระ → ฝ่ายวิชาการ → ผู้อำนวยการ) พร้อม audit trail, ลายเซ็นอิเล็กทรอนิกส์/ดิจิทัล, และคลังผลงานที่ค้นหาได้ ออกแบบให้สอดคล้องกับพระราชบัญญัติธุรกรรมทางอิเล็กทรอนิกส์ (พ.ศ. 2544), PDPA, และระเบียบการเก็บรักษาเอกสารราชการ

## เอกสารออกแบบระบบ

ดูรายละเอียดฉบับเต็ม (กฎหมายที่เกี่ยวข้อง, workflow, data model, การจัดเก็บไฟล์, ความปลอดภัย, สแตกเทคโนโลยีที่แนะนำ, และแผนงาน MVP/Roadmap) ได้ที่ [`docs/system-design.md`](docs/system-design.md)
