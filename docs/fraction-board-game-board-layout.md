# แผนผังกระดานเกม "ผจญภัยเกาะเศษส่วน" (Fraction Island Quest)

> เอกสารนี้ต่อยอดจาก [`fraction-board-game-design.md`](fraction-board-game-design.md) โดยแปลงแนวคิด 5 โซนเกาะ + ขุมทรัพย์กลาง ให้เป็นแผนผังกระดานที่มีพิกัด/ลำดับช่องชัดเจน พร้อมนำไปให้ทีมกราฟิกออกแบบภาพและส่งพิมพ์ได้จริง
>
> **หลักการออกแบบที่ยึดตลอดทั้งกระดาน:** ทุกช่องต้องมีหน้าที่ในเกม ไม่มีช่อง "ผ่านเฉย ๆ" — แม้แต่ช่องพัก (Rest) ก็ยังทำหน้าที่ควบคุมจังหวะเกมและให้ผู้เล่นได้พักคิด

---

## 1. ขนาดกระดานที่เหมาะสม

- **ขนาดกระดานเมื่อกางเต็ม: 55 × 55 ซม.** (สัดส่วนจัตุรัส เหมาะกับ path แบบวงเกลียว)
- **พับ 4 ทบ** (แบบกระดานเกมมาตรฐานทั่วไป) เหลือขนาดกล่อง **27.5 × 27.5 ซม.** พอดีมือเด็ก ป.5 หยิบเก็บ
- วัสดุแนะนำ: กระดาษอาร์ตการ์ด 300 แกรมเคลือบด้าน หรือฟิวเจอร์บอร์ด/เกรย์บอร์ดหุ้มกระดาษพิมพ์ (คงทนต่อการใช้งานซ้ำในห้องเรียน)
- ขนาดต่อ 1 ช่องบนกระดาน: ประมาณ **4.5 × 4.5 ซม.** (พอสำหรับวางหมากเดิน + พิมพ์ไอคอนประเภทช่องให้อ่านง่าย)
- แบ่งพื้นที่กระดานเป็น 2 ส่วน: **พื้นที่เล่นตรงกลาง (~40×40 ซม.)** สำหรับเส้นทางเดินและเกาะกลาง และ **กรอบขอบโดยรอบ (~7.5 ซม. ทุกด้าน)** สำหรับวางกองการ์ด แถบคะแนน และอุปกรณ์ (ดูข้อ 8–10)

---

## 2. จุดเริ่มต้น (START)

**"อ่าวเรืออับปาง" (Shipwreck Cove)** — วางที่ **มุมล่างซ้ายของกระดาน** เป็นภาพเรือแตกเกยตื้นบนชายหาด ผู้เล่นทุกคนวางหมากเริ่มต้นที่ช่องนี้พร้อมกัน ยังไม่นับเป็นช่องภารกิจ (ไม่ต้องตอบโจทย์ตอนเริ่ม)

---

## 3. จุดสิ้นสุด (FINISH)

**"ประตูขุมทรัพย์" (Treasure Gate)** — วางไว้ที่ **กึ่งกลางกระดานพอดี** เป็นเกาะวงกลมขนาดใหญ่กว่าช่องปกติ (เส้นผ่านศูนย์กลาง ~8–9 ซม.) ล้อมด้วยลวดลายเกลียวคลื่นที่ทุกโซนเกาะวนเข้ามาบรรจบ

เข้าช่องนี้ได้เมื่อผู้เล่นมี **เศษแผนที่ครบ 5 ชิ้น** เท่านั้น และเมื่อเข้าถึงต้องผ่านภารกิจสุดท้าย: **เรียงลำดับเศษส่วนบนการ์ดเศษแผนที่ทั้ง 5 ใบจากน้อยไปมากให้ถูกต้อง** จึงจะชนะเกม

---

## 4. เส้นทางการเดิน (Path Route)

เส้นทางออกแบบเป็น **"เกลียววนจากขอบกระดานเข้าสู่ใจกลาง"** ผ่าน 5 โซนเกาะตามลำดับความยาก (ตรงกับหลักสูตร ป.5): โซน 1 อยู่รอบนอกสุด วนทวนเข้าด้านในทีละโซนจนถึงโซน 5 ที่อยู่รอบในสุดก่อนถึงประตูขุมทรัพย์กลางกระดาน

> **หมายเหตุสำหรับกราฟิก:** แผนผังข้อความด้านล่างเขียนแบบ "งูเลื้อย" (บรรทัดสลับทิศ) เพื่อให้อ่านลำดับช่องง่ายเหมือนตัวอย่างที่กำหนด แต่เมื่อวาดจริงบนกระดาน ให้ **ม้วนเส้นทางแต่ละโซนให้โค้งเป็นวงแหวนรอบเกาะกลาง** ตามคำอธิบายเส้นทางด้านบน — ลำดับช่อง (ตัวเลข) และการเชื่อมต่อยังคงเดิมทุกประการ ต่างกันแค่รูปทรงที่วาด

```
[START — อ่าวเรืออับปาง มุมล่างซ้ายกระดาน]
        ↓
════════════════ วงที่ 1 (นอกสุด): เกาะเริ่มต้น — เศษส่วนแท้ / เกิน / จำนวนคละ ════════════════
 ช่อง1 → ช่อง2 → ช่อง3 → ช่อง4
                                ↓
 ช่อง8 ← ช่อง7 ← ช่อง6 ← ช่อง5
   ↓ (สะพานข้ามคลื่นสู่เกาะถัดไป)
════════════════ วงที่ 2: เกาะกระจก — เศษส่วนเท่ากัน / เศษส่วนอย่างต่ำ ════════════════
 ช่อง9 → ช่อง10 → ช่อง11 → ช่อง12
                                   ↓
 ช่อง16 ← ช่อง15 ← ช่อง14 ← ช่อง13
   ↓
════════════════ วงที่ 3: เกาะตาชั่ง — เปรียบเทียบ / เรียงลำดับเศษส่วน ════════════════
 ช่อง17 → ช่อง18 → ช่อง19 → ช่อง20
                                    ↓
 ช่อง24 ← ช่อง23 ← ช่อง22 ← ช่อง21
   ↓
════════════════ วงที่ 4: เกาะสะพานเชื่อม — บวก–ลบเศษส่วน / จำนวนคละ ════════════════
 ช่อง25 → ช่อง26 → ช่อง27 → ช่อง28
                                    ↓
 ช่อง32 ← ช่อง31 ← ช่อง30 ← ช่อง29
   ↓
════════════════ วงที่ 5 (ในสุด): เกาะประตูมิติ — คูณ / หารเศษส่วน ════════════════
 ช่อง33 → ช่อง34 → ช่อง35 → ช่อง36
                                    ↓
 ช่อง40 ← ช่อง39 ← ช่อง38 ← ช่อง37
   ↓
        [FINISH — ประตูขุมทรัพย์ ใจกลางกระดาน]
        (ต้องมีเศษแผนที่ครบ 5 ชิ้น + ผ่านภารกิจเรียงลำดับเศษส่วน)
```

**เส้นทางลัด (Shortcut Bridge):** จากช่อง27 (วงที่ 4) มีสะพานแยกเชื่อมตรงไปยังช่อง37 (วงที่ 5) — ผู้เล่นที่ตอบโจทย์ระดับยาก (การ์ดผสมของวงก่อนหน้า) ที่ช่อง27 ถูก มีสิทธิ์เลือกกระโดดข้ามไปช่อง37 ได้ทันที (เป็นเส้นทางเสี่ยง-ได้ ไม่ใช่เส้นทางบังคับ)

## 8. ตำแหน่งวางกองการ์ด

วางในกรอบขอบกระดาน (พื้นที่ ~7.5 ซม. รอบพื้นที่เล่น) ให้ใกล้กับโซนเกาะที่เกี่ยวข้องมากที่สุด:

| กองการ์ด | ตำแหน่งวางบนกระดาน |
|---|---|
| การ์ดโจทย์โซน 1 (เกาะเริ่มต้น) | มุมล่างซ้าย ใกล้ช่อง 1–8 |
| การ์ดโจทย์โซน 2 (เกาะกระจก) | ขอบซ้ายกลาง ใกล้ช่อง 9–16 |
| การ์ดโจทย์โซน 3 (เกาะตาชั่ง) | ขอบบนซ้าย ใกล้ช่อง 17–24 |
| การ์ดโจทย์โซน 4 (เกาะสะพานเชื่อม) | ขอบบนขวา ใกล้ช่อง 25–32 |
| การ์ดโจทย์โซน 5 (เกาะประตูมิติ) | ขอบขวากลาง ใกล้ช่อง 33–40 |
| การ์ดเหตุการณ์ (Event Card) | มุมล่างขวาของกระดาน (กองรวม ใช้ได้ทุกโซน) |
| การ์ดไอเทม/เครื่องมือ (Tool Card) | ถัดจากกองการ์ดเหตุการณ์ มุมล่างขวา |
| **พื้นที่รวมเศษแผนที่ (Map Assembly Area)** | รอบ ๆ ประตูขุมทรัพย์กลางกระดาน — ที่ว่างสำหรับผู้เล่นวางการ์ดเศษแผนที่ 5 ใบเรียงลำดับตอนภารกิจสุดท้าย |

## 9. ตำแหน่งวางคะแนน/เหรียญ

**แถบคะแนนความรู้ (Knowledge Point Track)** ออกแบบเป็นแถบเลขวิ่งรอบขอบนอกสุดของกระดาน (0 ถึง 30+) ให้ผู้เล่นเลื่อนโทเคนคะแนนของตนเองไปตามแถบทุกครั้งที่ได้แต้มความรู้ — วางแถบนี้ **ล้อมรอบพื้นที่เล่นทั้งหมดเป็นกรอบสี่เหลี่ยมชั้นนอกสุด** (อยู่นอกวงที่ 1 ของเส้นทางเดิน) เพื่อให้มองเห็นสถานะคะแนนของทุกคนได้ตลอดเกมโดยไม่บังเส้นทางเดิน

## 10. ตำแหน่งวางอุปกรณ์อื่น ๆ

| อุปกรณ์ | ตำแหน่ง |
|---|---|
| ลูกเต๋า + ถาดทอย | มุมล่างซ้ายสุดของกรอบกระดาน (ใกล้ START) |
| นาฬิกาทราย 60 วินาที (แต้มโบนัสตอบเร็ว) | ถัดจากถาดทอยลูกเต๋า มุมล่างซ้าย |
| ที่เก็บหมากเดิน 4 สี (ก่อนเริ่มเกม) | ช่อง START โดยตรง |
| กติกาเกมแบบย่อ (Quick Reference) | พิมพ์ไว้ที่ขอบล่างกระดาน ใต้กองการ์ดเหตุการณ์/ไอเทม |
| สัญลักษณ์คำอธิบายไอคอนช่อง (Legend) | มุมบนซ้ายของกระดาน คู่กับชื่อเกมและโลโก้ |

## สรุปสำหรับทีมกราฟิก

- กระดานจัตุรัส 55×55 ซม. พับ 4 ทบ, เส้นทางเกลียว 5 ชั้นจากขอบเข้าใจกลาง, รวม 42 ตำแหน่ง (40 ช่องภารกิจ + START + FINISH)
- ทุกช่องมีไอคอนกำกับประเภทชัดเจนตามตารางข้อ 6–7 ไม่มีช่องเปล่า
- กรอบขอบกระดานแบ่งเป็น 4 ด้าน: ล่าง=START/ลูกเต๋า/นาฬิกาทราย, ซ้าย=กองการ์ดโซน1–2, บน=กองการ์ดโซน3–4, ขวา=กองการ์ดโซน5/เหตุการณ์/ไอเทม, รอบนอกสุด=แถบคะแนนความรู้
- สีประจำโซนแนะนำ (ช่วยแยกภาพและช่วยครูอธิบายกติกา): โซน1 สีเหลืองทราย, โซน2 สีฟ้าใส (กระจก), โซน3 สีเขียวมะกอก (ตาชั่ง/ป่า), โซน4 สีน้ำตาลไม้ (สะพาน), โซน5 สีม่วงเวทมนตร์ (ประตูมิติ), ประตูขุมทรัพย์กลาง สีทอง
