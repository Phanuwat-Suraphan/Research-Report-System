# ชุด Asset Specification — "ผจญภัยเกาะเศษส่วน" (Fraction Island Quest)

> **ข้อจำกัดสำคัญ:** เซสชันนี้ไม่มีเครื่องมือสร้างภาพ เอกสารนี้จึงเป็น **สเปกและพรอมต์สำหรับส่งต่อให้นักวาดภาพประกอบ หรือใช้กับเครื่องมือสร้างภาพ AI ภายนอก** ไม่ใช่ไฟล์ภาพจริง ทุก Asset ยึดตาม [Art Direction & Style Guide](fraction-board-game-art-direction.md) ที่ออกแบบไว้ก่อนหน้าอย่างเคร่งครัด เพื่อให้ภาพทั้งหมดอยู่ใน "โลกเดียวกัน"
>
> เนื้อหาคณิตศาสตร์ที่ปรากฏใน Asset (เช่น ภาพเศษส่วนในหมวด B/K) อ้างอิงแนวคิดมาตรฐาน ป.5 เดียวกับเอกสารก่อนหน้าทั้งหมด — **ไม่มีสูตร/แนวคิดที่ขัดแย้งกับเนื้อหามาตรฐาน**

**ข้อกำหนดร่วมของทุก Asset (ยกเว้นระบุเป็นอย่างอื่น):** ไม่มีข้อความภาษาไทยในภาพ (ยกเว้นระบุ), พื้นหลังโปร่งใส/เรียบเพื่อตัดใช้งานต่อได้, ขอบมน silhouette อ่านง่าย, เหมาะเด็ก ป.5, ไม่มีรายละเอียดเล็กเกินไปที่หายเมื่อพิมพ์

## A. Character Assets (ตัวหมากผู้เล่น 4 ตัว)

| ตัวละคร | คำอธิบาย | สีประจำตัว |
|---|---|---|
| Character 1 — นักผจญภัยนักคณิตศาสตร์ | เด็กสวมหมวกผจญภัย ถือสมุดบันทึกเศษส่วน ท่าทางกระตือรือร้น | น้ำเงิน-ฟ้า |
| Character 2 — นักประดิษฐ์เครื่องมือเศษส่วน | เด็กสวมแว่นตา ถือเครื่องมือ/เข็มทิศรูปเศษส่วน | เขียวมิ้นท์ |
| Character 3 — นักสำรวจดินแดนตัวเลข | เด็กสะพายเป้ ถือแผนที่ ท่าทางมั่นใจ | ส้มทอง |
| Character 4 — นักเวทแห่งเศษส่วน | เด็กสวมเสื้อคลุมนักเวทลายเศษส่วน ถือคทาปลายรูปดาว | ม่วงอ่อน |

**Asset ที่ต้องสร้างต่อ 1 ตัวละคร (รวม 4×6 = 24 ไฟล์):** Full body, Front view, Side view, Happy pose, Thinking pose, Celebrating pose

| ฟิลด์ | ค่ามาตรฐาน (ใช้กับทุกไฟล์ในหมวด A) |
|---|---|
| Purpose | ใช้เป็นภาพตัวหมากเดิน, การ์ดเหตุการณ์, สไลด์นำเสนอ |
| Recommended Size | 2000×2000 px (สี่เหลี่ยมจัตุรัส, พิมพ์ตัวหมากจริงย่อเหลือสูง 4–5 ซม.) |
| Orientation | Portrait (full body/pose) ยกเว้น Side view เป็น profile |
| Background Requirement | โปร่งใส (transparent PNG) |
| Where it will be used | ตัวหมากผู้เล่น (standee), การ์ดเหตุการณ์, สไลด์ 1/3/12, สื่อประกอบครู |

## B. Fraction Visual Assets (ภาพประกอบแนวคิดเศษส่วน — ทำหน้าที่เป็น Visual Aid)

| Asset Name | Purpose |
|---|---|
| วงกลมแบ่งส่วนเท่ากัน (Fraction Circle) | แสดงเศษส่วนพื้นฐานด้วยพื้นที่วงกลม ใช้บนการ์ดโจทย์โซน 1–2 |
| สี่เหลี่ยมแบ่งส่วนเท่ากัน (Fraction Square) | ทางเลือกแสดงเศษส่วนแบบพื้นที่สี่เหลี่ยม |
| แถบเศษส่วน (Fraction Strip) | แสดงเศษส่วนแบบแท่งยาว ใช้เทียบหลายค่าพร้อมกัน (โซน 3 เปรียบเทียบ) |
| การแสดงเศษส่วนด้วยพื้นที่ (Area Model) | ภาพรวมสำหรับโจทย์ปัญหาที่อ้างอิงพื้นที่/ปริมาณ |
| การเปรียบเทียบเศษส่วน | สองรูปเทียบข้างกัน + สัญลักษณ์ > < = |
| การเรียงลำดับเศษส่วน | ชุดรูปเรียงจากน้อยไปมากบนเส้นจำนวน |
| จำนวนคละ (Mixed Number) | วงกลมเต็ม + วงกลมแบ่งบางส่วน |
| เศษส่วนเกิน (Improper Fraction) | วงกลมหลายวงรวมกันเกินหนึ่งหน่วย |
| ส่วนกลับของเศษส่วน (Reciprocal) | ภาพคู่เทียบเศษส่วนเดิมกับส่วนกลับ (สลับเศษ-ส่วน) |
| การบวกเศษส่วน | ภาพสองส่วนรวมกันเป็นภาพเดียว |
| การลบเศษส่วน | ภาพส่วนที่ถูกตัด/เอาออก |
| การคูณเศษส่วน | ภาพซ้อนทับพื้นที่สองมิติ (grid overlay) |
| การหารเศษส่วน | ภาพแบ่งกลุ่มย่อยเท่า ๆ กัน |

| ฟิลด์ | ค่ามาตรฐาน |
|---|---|
| Recommended Size | 1200×1200 px (สี่เหลี่ยมจัตุรัส ใช้แทรกในการ์ด/สไลด์ได้พอดี) |
| Orientation | Square |
| Background Requirement | โปร่งใส หรือพื้นขาวเรียบ (ห้ามใช้พื้นหลังธีมผจญภัยแทรก — ต้องอ่านค่าคณิตศาสตร์ชัด) |
| Where it will be used | การ์ดโจทย์/ภารกิจ, สไลด์ 5/11, สื่อประกอบครู |
| ข้อควรระวัง | สัดส่วนที่แบ่ง/แรเงาต้องตรงกับค่าเศษส่วนจริงเป๊ะ ตรวจทานก่อนส่งงานทุกภาพ |
