ผังกระดานเกม "ผจญภัยเกาะเศษส่วน"

แผนภาพเวกเตอร์แสดงเส้นทางเดินจริงทั้ง 42 ตำแหน่งบนกระดาน ไล่จาก START ผ่าน 5 เกาะ ไปจนถึงประตูขุมทรัพย์กลางกระดาน ตรงตามสเปกในเอกสารแผนผังกระดาน — ใช้เพื่อดูภาพรวม ไม่ใช่ไฟล์ภาพประกอบสำเร็จรูปสำหรับพิมพ์จริง

เส้นประสีทองคือเส้นทางลัด (ช่อง 27 → 37) แถบสีพื้นหลังแต่ละช่วงคืออาณาเขตของแต่ละเกาะ (อ้างอิงจาก fraction-board-game-board-layout.md) ตัวเลขในวงกลมคือหมายเลขช่อง ไอคอนคือประเภทช่องตาม 8 หมวดที่กำหนดไว้ — เมื่อผลิตกราฟิกจริง ให้นักวาดใช้แผนผังนี้เป็นแผนที่อ้างอิงตำแหน่ง แล้ววาดภาพประกอบเกาะ/เส้นทาง/ไอคอนทับตามสไตล์ที่กำหนดใน Art Direction แทนวงกลมเรียบง่ายนี้
