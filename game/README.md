# ศึกชิงปราสาทตัวเลข — บอร์ดเกมเดินได้

บอร์ดเกมผจญภัยแดนคณิตศาสตร์แบบเล่นบนจอ (ทอยลูกเต๋า → เดินตามช่อง → จั่วการ์ดโจทย์ → รับผลกรรม)
สร้างจากกระดาน/การ์ด/ตัวหมากของ "สุดยอดภารกิจ ป.4: พิชิตปีศาจด้วยสมการบวก ลบ คูณ หาร"

## วิธีเล่น

```bash
node server.js          # จากรากโปรเจกต์
```

เปิด <http://localhost:3000/game> (เล่นได้เลย ไม่ต้อง login)

## กติกาที่ระบบทำให้อัตโนมัติ

| องค์ประกอบ | พฤติกรรมในเกม |
|---|---|
| ทอยลูกเต๋า | สุ่ม 1–6 แล้วเดินทีละช่องแบบมีอนิเมชัน |
| ช่องสีเขียว | จั่วการ์ดเวทมนตร์ระดับ 1 (ง่าย) |
| ช่องสีฟ้า | จั่วการ์ดเวทมนตร์ระดับ 2 (ปานกลาง) |
| ช่องสีแดง | จั่วการ์ดเวทมนตร์ระดับ 3 (ยาก) |
| ตอบถูก | ได้คะแนนสะสม อยู่ช่องเดิม |
| ตอบผิด | ถอยหลัง 1 ช่อง |
| การ์ดนางฟ้า | เดินหน้าฟรี 2 ช่อง (ไม่ต้องตอบคำถาม) |
| การ์ดมังกร | ถอยหลัง 1 ช่องทันที |
| ช่องทางลัด (ช่อง 5) | กระโดดไปช่อง 10 ทันที |
| หลุมพราง (ระหว่างช่อง 8–9) | ถอยหลัง 2 ช่อง |
| ช่องพายุหมุน (ช่อง 17) | สลับตำแหน่งกับผู้เล่นรั้งท้าย — ถ้าเล่น 2 คน หยุดเดิน 1 ตา |
| ปราสาทตัวเลข (ช่อง 25) | ผู้ที่ถึงก่อนเป็นผู้ชนะ |

เส้นทางต่อเนื่องข้าม 2 แผนที่ (แผนที่ 1 ช่อง 1–12 → แผนที่ 2 ช่อง 13–25) ระบบสลับแผนที่ให้เองตามตำแหน่งผู้เล่น

## แก้ไขเนื้อหาโดยไม่ต้องแตะโค้ด

ทุกอย่างอ่านจากไฟล์ใน `data/`

- **`data/board.json`** — รูปแผนที่ ตำแหน่งช่อง (พิกัด % ของภาพ) ประเภทช่อง และระดับการ์ดของแต่ละช่อง
- **`data/cards.json`** — สำรับการ์ดทั้ง 4 ชุด (`easy` / `medium` / `hard` / `special`)
  พร้อมโจทย์ ตัวเลือก เฉลย (`answer` = ลำดับตัวเลือกที่ถูก เริ่มที่ 0) และผลได้/ผลเสีย
  `specialChance` = โอกาสที่จะได้การ์ดเหตุการณ์พิเศษแทนการ์ดโจทย์
- **`data/characters.json`** — รายชื่อและรูปตัวหมาก

### เพิ่มโจทย์ใหม่

เติมลงใน `cards.json` ในสำรับที่ต้องการ:

```json
{
  "id": "e4",
  "title": "โจทย์: 25 × 4",
  "text": "สถานการณ์...",
  "image": "",
  "options": ["100", "90", "110", "120"],
  "answer": 0,
  "reward": { "type": "points", "value": 10 },
  "penalty": { "type": "move", "value": -1 }
}
```

`type` ที่ใช้ได้: `points` (คะแนน) · `move` (เดินหน้า/ถอยหลัง) · `goto` (ไปช่องที่ระบุ) · `skip` (หยุดกี่ตา) · `reroll` (ทอยใหม่) · `none`

### ย้าย/เพิ่มช่องบนกระดาน

เปิด <http://localhost:3000/game/editor.html> → คลิกบนรูปเพื่อเพิ่มช่อง → ลากหมุดให้ตรงกับช่องในรูป →
แก้ประเภท/ข้อความทางขวา → กด **ดาวน์โหลด board.json** แล้วนำไปวางทับที่ `game/data/board.json`

ติ๊ก **แสดงหมุดช่อง** ในหน้าเกมเพื่อตรวจว่าหมุดตรงกับช่องในรูปหรือยัง
