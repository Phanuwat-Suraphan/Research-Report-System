# ศึกชิงปราสาทตัวเลข — บอร์ดเกมเดินได้

บอร์ดเกมผจญภัยแดนคณิตศาสตร์แบบเล่นบนจอ (ทอยลูกเต๋า → เดินตามช่อง → จั่วการ์ดโจทย์ → รับผลกรรม)
สร้างจากกระดาน/การ์ด/ตัวหมากของ "สุดยอดภารกิจ ป.4: พิชิตปีศาจด้วยสมการบวก ลบ คูณ หาร"

## วิธีเล่น

**แบบรันบนเซิร์ฟเวอร์** (แก้กระดานได้ด้วย)

```bash
node server.js          # จากรากโปรเจกต์
```

เปิด <http://localhost:3000/game> (เล่นได้เลย ไม่ต้อง login)

**แบบไฟล์เดียวจบ** (ส่งต่อ/อัปโหลดที่ไหนก็ได้ ไม่ต้องมีเซิร์ฟเวอร์)

```bash
node game/tools/build-standalone.js game/standalone.html
```

ได้ไฟล์ HTML ไฟล์เดียวที่ฝังรูปแผนที่ ตัวหมาก และการ์ดไว้ครบ ดับเบิลคลิกเปิดได้ทันที

## กติกาที่ระบบทำให้อัตโนมัติ

| องค์ประกอบ | พฤติกรรมในเกม |
|---|---|
| ทอยลูกเต๋า | สุ่ม 1–6 แล้วเดินทีละช่องแบบมีอนิเมชัน |
| ช่องสีเขียว | จั่วการ์ดเวทมนตร์ระดับ 1 (ง่าย) |
| ช่องสีฟ้า | จั่วการ์ดเวทมนตร์ระดับ 2 (ปานกลาง) |
| ช่องสีแดง | จั่วการ์ดเวทมนตร์ระดับ 3 (ยาก) |
| ตอบถูก | ได้คะแนนสะสม อยู่ช่องเดิม |
| ตอบผิด | ถอยหลัง 1 ช่อง |
| การ์ดนางฟ้า | เดินหน้าฟรี 2 ช่อง (ไม่ต้องตอบคำถาม) |
| การ์ดมังกร | ถอยหลัง 1 ช่องทันที |
| ช่องทางลัด (ช่อง 5) | กระโดดไปช่อง 10 ทันที |
| หลุมพราง (ระหว่างช่อง 8–9) | ถอยหลัง 2 ช่อง |
| ช่องพายุหมุน (ช่อง 17) | สลับตำแหน่งกับผู้เล่นรั้งท้าย — ถ้าเล่น 2 คน หยุดเดิน 1 ตา |
| ปราสาทตัวเลข (ช่อง 25) | ผู้ที่ถึงก่อนเป็นผู้ชนะ |

เส้นทางต่อเนื่องข้าม 2 แผนที่ (แผนที่ 1 ช่อง 1–12 → แผนที่ 2 ช่อง 13–25) ระบบสลับแผนที่ให้เองตามตำแหน่งผู้เล่น

## แก้ไขเนื้อหาโดยไม่ต้องแตะโค้ด

ทุกอย่างอ่านจากไฟล์ใน `data/`

- **`data/board.json`** — รูปแผนที่ ตำแหน่งช่อง (พิกัด % ของภาพ) ประเภทช่อง และระดับการ์ดของแต่ละช่อง
- **`data/cards.json`** — สำรับการ์ดทั้ง 4 ชุด (`easy` / `medium` / `hard` / `special`)
  พร้อมโจทย์ ตัวเลือก เฉลย (`answer` = ลำดับตัวเลือกที่ถูก เริ่มที่ 0) และผลได้/ผลเสีย
  `specialChance` = โอกาสที่จะได้การ์ดเหตุการณ์พิเศษแทนการ์ดโจทย์
- **`data/characters.json`** — รายชื่อและรูปตัวหมาก

### เพิ่มโจทย์ใหม่

เติมลงใน `cards.json` ในสำรับที่ต้องการ:

```json
{
  "id": "e4",
  "title": "โจทย์: 25 × 4",
  "text": "สถานการณ์...",
  "image": "",
  "options": ["100", "90", "110", "120"],
  "answer": 0,
  "reward": { "type": "points", "value": 10 },
  "penalty": { "type": "move", "value": -1 }
}
```

`type` ที่ใช้ได้: `points` (คะแนน) · `move` (เดินหน้า/ถอยหลัง) · `goto` (ไปช่องที่ระบุ) · `skip` (หยุดกี่ตา) · `reroll` (ทอยใหม่) · `none`

### ย้าย/เพิ่มช่องบนกระดาน

เปิด <http://localhost:3000/game/editor.html> → คลิกบนรูปเพื่อเพิ่มช่อง → ลากหมุดให้ตรงกับช่องในรูป →
แก้ประเภท/ข้อความทางขวา → กด **ดาวน์โหลด board.json** แล้วนำไปวางทับที่ `game/data/board.json`

ติ๊ก **แสดงหมุดช่อง** ในหน้าเกมเพื่อตรวจว่าหมุดตรงกับช่องในรูปหรือยัง

## โครงสร้างข้อมูล

| ไฟล์ | หน้าที่ |
|---|---|
| `data/board.json` | สไลด์แนะนำกติกา, รูปแผนที่, ตำแหน่งช่องทุกช่อง (หน่วยเป็น % ของภาพ) และผลของแต่ละช่อง |
| `data/cards.json` | สำรับการ์ด 4 สำรับ: ง่าย/ปานกลาง/ยาก (โจทย์คณิตศาสตร์) และเหตุการณ์พิเศษ (นางฟ้า/มังกร) |
| `data/characters.json` | ตัวหมากที่เลือกได้ |

### เส้นทางบนกระดาน

แผนที่ 1 มีช่องพิเศษที่ไม่มีเลขกำกับ 2 ช่องคั่นระหว่างช่อง 8 กับช่อง 9 คือ **ช่องมังกร** (ถอยหลัง 1 ช่อง)
แล้วต่อด้วย **หลุมพราง** (ถอยหลัง 2 ช่อง) ส่วนแผนที่ 2 ช่อง 13 เป็น **ช่องนางฟ้า** (เดินหน้าฟรี 2 ช่อง
ไม่ต้องตอบคำถาม) และช่อง 18 เป็น **ช่องพายุหมุน** (สลับตำแหน่งกับผู้เล่นรั้งท้าย หรือหยุด 1 ตาถ้าเล่น 2 คน)

### ตรวจโจทย์ก่อนใช้งานจริง

การ์ดโจทย์ทุกใบมีฟิลด์ `expr` (นิพจน์คณิตศาสตร์) กำกับไว้ ตรวจได้ด้วย:

```bash
node game/tools/verify-cards.js
```

สคริปต์จะคำนวณ `expr` แล้วเทียบกับตัวเลือกที่ทำเครื่องหมายว่าถูก พร้อมตรวจตัวเลือกซ้ำ
และความครบถ้วนของวิธีทำ/ผลได้/ผลเสีย — **ควรรันทุกครั้งหลังแก้ไขโจทย์**

## เผยแพร่ให้นักเรียนเล่น

โฟลเดอร์นี้เป็นเว็บ static ล้วน จึงวางบนโฮสต์ฟรีได้ทุกเจ้า

### GitHub Pages (อัตโนมัติ)

`.github/workflows/deploy-game.yml` จะ deploy ให้เองทุกครั้งที่ push ไฟล์ในโฟลเดอร์ `game/`
ตั้งค่าครั้งเดียวที่ **Settings → Pages → Source: GitHub Actions** แล้วเกมจะอยู่ที่

```
https://phanuwat-suraphan.github.io/Research-Report-System/
```

และไฟล์เดียวจบสำหรับดาวน์โหลดไปเปิดออฟไลน์อยู่ที่ `<url>/standalone.html`

ก่อน deploy ทุกครั้ง workflow จะรัน `verify-cards.js` เป็นด่านกันเฉลยผิดหลุดไปถึงมือนักเรียน
ถ้าโจทย์ข้อไหนเฉลยไม่ตรงกับการคำนวณ จะ deploy ไม่ผ่าน

## ใบงานพิมพ์ได้

กดปุ่ม **🖨️ พิมพ์ใบงาน** ที่เมนูหลัก แล้วเลือกว่าจะพิมพ์ฉบับไหน

| ฉบับ | เนื้อหา |
|---|---|
| นักเรียน | โจทย์ 6 ด่าน เว้นช่องแสดงวิธีทำและช่องตอบ |
| ครู | โจทย์เดียวกัน พร้อมวิธีทำและคำตอบครบทุกด่าน |

ใบงานสร้างจาก `data/lesson.json` ชุดเดียวกับบทเรียน แก้โจทย์ที่เดียวใบงานอัปเดตตาม
ในหน้าต่างพิมพ์เลือก "บันทึกเป็น PDF" ได้ ขนาด A4 ประมาณ 4 หน้า

## เสียงอ่านและเสียงพากย์

บทเรียนและการ์ดโจทย์มีปุ่ม 🔊 อ่านให้ฟัง ใช้เสียงอ่านภาษาไทยที่ติดมากับเครื่อง
ถ้าเครื่องไม่มีเสียงไทย ระบบจะขึ้นข้อความบอกสาเหตุ ไม่ปล่อยให้เงียบ

อยากใช้เสียงพากย์จริงแทน (เล่นได้ทุกเครื่องโดยไม่ต้องพึ่งเสียงในระบบ):

1. สร้างบทพากย์จากเนื้อหาจริง — `node game/tools/make-voice-script.js`
   ได้ไฟล์ `game/บทพากย์.txt` แปลงเครื่องหมายคณิตศาสตร์เป็นคำพูดให้แล้ว
2. อัดเสียงตามบท ตั้งชื่อ `vo-story-1.mp3` … `vo-quest-6.mp3` วางใน `game/assets/`
3. ใส่ฟิลด์ `audio` ในสไลด์ที่ต้องการใน `data/lesson.json`
4. build ใหม่ — ระบบจะเล่นไฟล์เสียงก่อนเสียงสังเคราะห์เสมอ

### ตรวจความสอดคล้องของข้อมูล

```bash
node game/tools/verify-data.js
```

ตรวจว่าไฟล์รูป/เสียงที่อ้างถึงมีอยู่จริง ช่องอ้างสำรับและการ์ดที่มีจริง เลขช่องไม่ซ้ำกัน
และปลายทางของช่องทางลัดชี้ไปยังช่องที่ถูกต้อง

> จุดที่พลาดง่ายที่สุดคือ **ช่องพิเศษที่ไม่มีเลข** (ช่องมังกร หลุมพราง) ทำให้ id ภายใน
> ไม่ตรงกับเลขที่พิมพ์บนกระดาน ถ้าอ้างปลายทางด้วย id ช่องทางลัดจะพาไปโผล่ผิดช่อง
> ตัวตรวจจับกรณีนี้ได้ และ workflow จะไม่ยอม deploy
